B. Limits of the tool (shown in every report)
Seeing a condition in a file is not seeing the attack. AgentReach cannot see:
  1. The agent version. Some attacks depend on the agent having a defect in a
     certain version; AgentReach does not know it.
  2. Whether the AI model would obey. A file with a hidden order is a
     condition; whether the model follows it depends on the model.
  3. Malicious instructions written in plain language, with no formatting
     tricks. Only very simple phrases are flagged, at most as a hypothesis.
  4. The descriptions of MCP tools (the agent's link to external tools). They
     only appear when the server runs, and AgentReach runs nothing.
  5. Packages made up by the model. Knowing whether a package exists needs the
     internet, and AgentReach does not go online.
  6. The real power of a token. It sees that a token exists and what kind it
     is, not what it could do on the service.
Also not checked in this version: git commit history, changes to a
configuration after it was approved, and running processes and ports.
