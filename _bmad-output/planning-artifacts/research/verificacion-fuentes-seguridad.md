## Recuento

- Confirmadas: 7 (3, 4, 5, 7, 9, 11, 12).
- Parcialmente: 5 (1, 2, 6, 8, 10).
- Contradichas: dos puntos dentro de afirmaciones parciales (Shai-Hulud no usa agentes de IA según la fuente abierta; los hooks de Claude Code no corrían antes del aviso de confianza ni llevan el CVE-2025-59536) y una nota del propio informe (la 1.109 sí menciona el ajuste).
- No se pudo confirmar: ninguna afirmación completa; sí detalles sueltos (nombres exactos de las banderas de s1ngularity en fuente primaria, el hilo del fundador de PocketOS, el informe de Manifold, el aviso de MSRC, la comprobación práctica de la hipótesis 8).

## Qué cambia para el diseño de AgentReach

1. Los hallazgos de configuración de proyecto de Claude Code deben distinguir tres casos: hooks (corren tras aceptar el aviso), MCP y `ANTHROPIC_BASE_URL` (corrían antes del aviso, versiones anteriores a 1.0.111 y 2.0.65). La lista de versiones afectadas puede citar números oficiales.
2. La señal "agente instalado más secretos legibles" sigue siendo válida con s1ngularity, pero no hay que atribuir esa técnica a Shai-Hulud.
3. Reportar `task.allowAutomaticTasks: "on"` como freno desactivado; el valor por defecto actual protege.
4. En opencode, un `deny` de lectura o edición no protege frente al shell, y `permission` puede llamarse `shell`: el lector debe aceptar ambos nombres y no bajar un hallazgo por una regla `deny`.
5. La puerta previa de git queda reforzada: `gpg.program` + `log.showSignature` y `credential.helper`/alias con `!` están respaldados por la documentación; mantener la decisión de no ejecutar git en el MVP.
6. Para Git for Windows, el aviso de versión mínima debe incluir 2.53.0.windows.4 como mínimo para Clone2Creds, y advertir que los fallos de `wincred` de septiembre de 2026 no tienen corrección: sugerir otro ayudante de credenciales.
